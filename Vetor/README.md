1- Faça um programa que leia até seis characteres e grave num vetor na ordem inserida.
Imprima o vetor da primeira a ultima posição e da ultima a primeira posição

2- Faça um programa que leia 5 numeros inteiros e grave em um vetor. 
Este vetor deve ser copiado para um novo vetor na sequencia inversa 
Faça o mesmo copiando para um novo vetor os numeros pares e para outro os numeros impares
Mostre todos os vetores.

3- Faça um programa que leia um numero inteiro. 
Usando esse numero, crie um vetor com essa quantidade de posições. 
Dentro deste vetor, deve conter os itens da sequencia fibonacci até a posição informada 

4 - Faça um programa que cria um vetor de char de 10 posições.
Então, faça um novo vetor de string com o dobro de posições que armazena o char e o valor ASCII dele logo em sequencia 
(exemplo: "Casa"->C21A34S55A11)
